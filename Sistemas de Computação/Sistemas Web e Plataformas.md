# Sistemas Web e Plataformas

## Ementa

Modelo cliente–servidor; padrões Web e recomendações do W3C; HTML, CSS e JavaScript; fundamentos de HTTP e HTTPS; Sistema de Nomes de Domínio (DNS), nomes de domínio, endereços IP e portas; desenvolvimento *front-end* com HTML, incluindo formulários e validação de entradas; estilização com CSS; programação em JavaScript e manipulação do Modelo de Objetos do Documento (DOM); compatibilidade entre navegadores; otimização de desempenho; *frameworks* de desenvolvimento, como React, Vue e Angular; arquitetura baseada em componentes; desenvolvimento *back-end* com tecnologias como Node.js, Python/Django, PHP e Ruby; ciclo de requisição e resposta; integração com bancos de dados; projeto e consumo de APIs RESTful; métodos HTTP, incluindo GET, POST, PUT, PATCH e DELETE; serialização de dados em JSON; padrões arquiteturais MVC e MVVM; autenticação e autorização por sessões, *cookies* e OAuth 2.0; segurança de aplicações Web, incluindo XSS, CSRF, HTTPS e TLS; implantação, hospedagem e execução de aplicações em plataformas Web e serviços de nuvem.
